# 아트 컨셉 시안

`index.html`을 브라우저로 열면 된다(저장소 안 초상화·바닥 질감을 상대 경로로 읽으므로 저장소 구조를 유지할 것).
같은 게임 화면(rooms.json 좌표 · 엿듣기 슬라이스 0:34 시점)을 열두 연출로 그린 것이고, `png/`에 1600×900 스크린샷이 있다.

| # | 시안 | 기법 |
|---|---|---|
| 01 | 사건 파일 | 현행 연출 정제 — 실제 바닥 질감, 종이 패널, 붉은 잉크 |
| 02 | 청사진 | 도면 — 격자·해칭 벽·치수선·시아노타입 초상 |
| 03 | 필름 누아르 | 흑백 고대비 — 블라인드 빛·긴 그림자·그레인 |
| 04 | 동판화 | 해칭 패턴·이중선·포스터라이즈 초상 |
| 05 | 종이 극장 | 오려 붙인 종이 층·조명·커튼 |
| 06 | 아르데코 | 검정 + 금 상감·메달리온·선버스트 |
| 07 | 먹과 한지 | 변위 필터 붓선·먹 번짐·낙관 |
| 08 | 픽셀 아트 | 400×225 캔버스 렌더·16색·주사선 |
| 09 | 코르크 보드 | 핀·붉은 실·폴라로이드·색인 카드 |
| 10 | 소나 | 파문 애니메이션·가청 원·성문 |
| 11 | 수채 삽화 | 물감 번짐·연필 벽·어긋남 |
| 12 | 인형의 집 | 아이소메트릭 투영·컷어웨이·화가 알고리즘 |

스크린샷 재생성: `node shoot.js` (playwright + chromium). 폰트는 Google Fonts에서 받아 `fontcache/`에 캐시한다(커밋하지 않는다).
