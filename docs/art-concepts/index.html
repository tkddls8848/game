블랙우드 저택, 열두 가지 그림

같은 게임 화면을 열두 연출로 그린 시안이다. 화면은 전부 실제 데이터로 세웠다. 방과 문은 rooms.json의 좌표(36 × 24 m, 방 6·문 5), 목소리와 시각은 엿듣기 슬라이스 대본(script_slice.json) 0:34 시점, 초상화는 지금 저장소에 든 사전트·소른 그림이다.

각 시안은 같은 순간을 보여 준다. 청취점이 복도 식당 문 앞에 서 있고, 복도의 목소리 2는 또렷하게, 식당 안 목소리 1은 멀어서 글자가 빠진 채 들린다. 아래 오른쪽 판은 "누구의 목소리인가"를 맞히는 식별 보드다.

다음에 손댈 셋

지금 연출(사건 파일)을 버리지 않고도 시험할 수 있는 순서다.

① 소나 — 엿듣기 전용 화면인물이 익명이고 소리만 단서인 게임에 가장 정직한 그림이다. 링·가청 반경·글자 빠짐은 전부 코드로 그려서 외부 에셋이 0이다. 사건 파일 종이 패널 위에 관찰 모드(T)로만 얹어 봐도 된다.
② 코르크 보드 — 식별 보드의 형태수사 노트를 "인물 식별 보드"로 바꾸는 Phase에 그대로 쓸 수 있는 UI 언어다. 붉은 실·핀·폴라로이드는 전부 uGUI 이미지 몇 장으로 되고, 초상화는 지금 것을 그대로 쓴다.
③ 청사진 — 관찰 모드의 대안 스킨평면도를 도면으로 읽게 하면 "치수·시각·위치"가 정보로 보인다. 선 색 두 개와 격자 패턴만 있으면 되므로 SceneBuilder에서 바닥 질감을 끄고 선만 남기는 옵션 하나로 시험할 수 있다.
초상화·단서 그림은 저장소의 Assets/Resources/Art/에 든 퍼블릭 도메인 회화를 각 시안의 필터로 다시 칠한 것이다(CREDITS.md). 시안의 무늬·질감·선은 전부 SVG 패턴·필터, 캔버스, CSS로 그려서 외부 그림을 쓰지 않았다.
